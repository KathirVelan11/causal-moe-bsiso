\section{Reproduction}

From \path{code/}, with the pinned environment (\path{requirements.txt}) and the archive under \path{data/raw/rt_preprocessed_archive/}:
\begin{lstlisting}
python -m pytest tests
python scripts/build_mesh_cache.py
python scripts/phase1_build_graph.py                 # Stages A-B (~2.5 h)
python scripts/phase1_run_stage_c.py --pools full --priors none,pcmci --modes restrict
python scripts/run_step5_drift.py                    # drift channels
python scripts/run_step6_lifecycle.py                # expert lifecycle
python scripts/phase1_stage_d_drift.py --window-seasons 1
python scripts/generate_phase1_figures.py
\end{lstlisting}
The workflow figures are TikZ sources in \path{thesis/figures/workflows/}; the lifecycle and 1-day Stage~C figures are produced by \path{thesis/scripts/}.
